Resgate local — Projeto Salobo

Este utilitário consulta apenas os dados locais deste navegador, na origem GitHub Pages do projeto. Não acessa Supabase, não envia dados a nenhum servidor e não modifica os aplicativos.

Abra neste mesmo navegador e dispositivo utilizado para marcar atividades em Recuperação da Infraestrutura. Exporte uma cópia de cada aparelho dos responsáveis.

O arquivo contém as marcações locais e filas de sincronização do projeto. Envie-o apenas à coordenação. Não é prova de que o Supabase tenha confirmado a alteração.
